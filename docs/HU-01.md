# HU-01 — Base Architecture

## Description

As a system administrator, I want to register and visualize both events
and venues in an organized way, in order to validate the initial catalog
logic and ensure the stability of the base architecture.

## Acceptance Scenarios

| Scenario | Description | Expected Result |
|----------|-------------|-----------------|
| 1 | POST with valid event data | 201 Created |
| 2 | POST with empty name | 400 Bad Request |
| 3 | GET with empty catalog | 200 OK with [] |
| 4 | Access /swagger-ui/index.html | All endpoints documented |

## Layers Implemented

- **Model** → `Event` (id, name, date, description) / `Venue` (id, name, address, capacity)
- **Repository** → In-memory List simulating a database
- **Service** → Business validations with constructor injection
- **Controller** → REST endpoints with correct HTTP status codes
- **Config** → DataSeeder, OpenApiConfig, GlobalExceptionHandler

## Endpoints

### Events
| Method | Endpoint | Description | Status |
|--------|----------|-------------|--------|
| GET | /api/events | List all events | 200 OK |
| POST | /api/events | Register new event | 201 Created |

### Venues
| Method | Endpoint | Description | Status |
|--------|----------|-------------|--------|
| GET | /api/venues | List all venues | 200 OK |
| POST | /api/venues | Register new venue | 201 Created |

## Tests

| Test | Description |
|------|-------------|
| `create_withValidData_returnsSavedEvent` | Happy path — valid event saved |
| `create_withEmptyName_throwsException` | Empty name blocked at service layer |
| `create_withNullName_throwsException` | Null name blocked at service layer |
| `findAll_returnsEventList` | Returns list from repository |
| `create_withValidData_returnsSavedVenue` | Happy path — valid venue saved |
| `create_withEmptyName_throwsException` | Empty name blocked at service layer |
| `create_withNullName_throwsException` | Null name blocked at service layer |
| `findAll_returnsVenueList` | Returns list from repository |

## Notes

- All data is stored in memory (no database yet)
- Seeder loads 2 events and 2 venues on startup
- To test empty catalog scenario, comment out the seeder body in `DataSeeder.java`
